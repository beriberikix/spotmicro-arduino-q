# Fit-test prints

Print these before the full robot. They take about 2 hours and 62 g of filament, and check every place where a printed
part has to fit something you bought: the UNO Q, the servo regulator, a servo and its horn, and the 625ZZ bearings.
If they fit, the other 76 parts will fit too, since they share the same printer tolerances and the same designs.

## Files

| File | What it is |
| ---- | ---------- |
| `makerworld/SpotUnoQ_P1S_test_prints.3mf` | Bambu Studio project, sliced for the P1S (0.4 mm nozzle, 0.20 mm Standard, Textured PEI plate). Not committed; build it with the command below. |
| [`stl/optional/test-prints/UnoQ_Mount_Test.stl`](../stl/optional/test-prints/UnoQ_Mount_Test.stl) | The UNO Q standoffs from the electronics plate on a 2 mm frame |
| [`stl/optional/test-prints/Pololu_Mount_Test.stl`](../stl/optional/test-prints/Pololu_Mount_Test.stl) | The Pololu D24V150F6 posts from the electronics plate on a 2 mm frame |

Build the project:

```sh
python3 scripts/build_makerworld_3mf.py --no-orient --test-prints
```

The two test frames are generated by `scripts/export_stls.py` from the electronics plate's actual standoffs and its
`Params` spreadsheet, so they always match the current plate. Re-run that script, then the build, after changing the plate.

Print settings match the real parts: 3 walls, 20% infill, Bambu PLA Basic, no supports.

## What you need on hand

- Arduino UNO Q
- Pololu D24V150F6 regulator
- One servo (DS3218MG or MG996R) with its rubber dampeners and a 25T six-arm horn
- Two 625ZZ bearings
- Screws: 4× M3x8, 4× M2x6, M3x20 + nuts (servo and shoulder cover), M2x8 + nuts (horn and Kooba pin)

## Checks

| Part | Check | Passes when |
| ---- | ----- | ----------- |
| UnoQ_Mount_Test | Screw the UNO Q on with 4× M3x8 | All four holes line up without forcing the board; screws bite into the 2.6 mm pilot holes and hold; the bottom JMISC/JMEDIA connectors don't touch the frame |
| Pololu_Mount_Test | Screw the regulator on with 4× M2x6 | All four holes line up; screws bite into the 1.8 mm pilot holes |
| Shoulder_Joint_Servomount_extended_BB | Fit the servo with its dampeners, M3x20 + nuts | The servo body slides in without filing and the mounting holes line up |
| Shoulder_Joint_Servo_Cap_Extended | Seat the servo horn, M2x8 screws | The horn sits flat in its recess and the screw holes line up with the horn's arms |
| Limb_Ball_Bearing_Mount_long_v4 | Press in a 625ZZ | The bearing presses in by hand or with light pressure and stays put |
| Shoulder_Cover | Press in a 625ZZ; hold against the cap's extension with M3x20 + nuts | The bearing seats in the 16.3 mm bore; the cover's screw holes line up with the cap |
| Shoulder_Joint_Ball_Bearing_Pin (Kooba, M2 bore) | Slide into the second bearing | The 5 mm pin goes into the bearing's centre snugly, without wobble |
| Shoulder_Joint_Ball_Bearing_Pin_M3x8 (robjk, M3 bore) | Same | Same |

## If something doesn't fit

**UNO Q or regulator mounts**: these are this project's own design, so change the electronics plate's `Params`
spreadsheet in `cad/UnoQ_Mountingplate.FCStd`, then regenerate the STLs and both projects:

| Problem | Parameter |
| ------- | --------- |
| M3 screws too tight or loose in the standoffs | `Screw_D` (default 2.6 mm) |
| Board connectors touch the frame, or you want more room for wiring underneath | `Standoff_H` (default 8 mm) |
| Standoffs crack when screwing | `Standoff_D` (default 6 mm) |
| Regulator holes don't line up (different regulator) | `Buck_SX`, `Buck_SY` |
| M2 screws too tight or loose in the regulator posts | `Buck_Screw_D` (default 1.8 mm) |

```sh
/Applications/FreeCAD.app/Contents/Resources/bin/freecadcmd scripts/export_stls.py
python3 scripts/build_makerworld_3mf.py --no-orient --test-prints
python3 scripts/build_makerworld_3mf.py --no-orient
```

**Servo, horn, bearing and pin fits**: these are Kooba's and robjk's designs, printed successfully by many builders,
so a bad fit usually means the printer, not the model. Before editing any CAD:

- Run Bambu Studio's flow-rate calibration for the filament.
- If holes and bearing bores are tight but outside dimensions are right, set **X-Y hole compensation** (Process →
  Quality) to about +0.1 mm and re-slice. If pins and other outside dimensions are oversized, use **X-Y contour
  compensation** instead.
- Change these in the full robot project too, so the real parts print the same way.
