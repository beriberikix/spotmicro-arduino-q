Sorting the hardware first turns a 250-screw build into a series of small, countable kits, and you'll see straight away
if anything is missing. Use small zip bags, cups or an egg carton, and label each one with its letter.

Each bag's first table lists its hardware step by step; the **total** under it is what to count into the bag. Bags
A–D are **per leg**: make four of each, so the totals give both one bag and all four. [Totals](#totals) at the end adds
up every bag.

<Aside type="tip" title="Pre-thread the horn screws">
For bags B, D and E, screw an M2 nut all the way onto each M2×8 now. The nut is a spacer: a bare M2×8
pokes through the horn and rubs on the servo. If you have M2×6 screws, use those instead and skip the nuts. Two screws per
horn are enough, if you're short.
</Aside>
